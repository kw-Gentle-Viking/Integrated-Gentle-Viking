## 이번에 같이 고친 것

- `Front-Gentle-Viking` 사이드바에서 "내 주식보기" 메뉴 글자가 두 줄로 밀리던 문제 —
  `whitespace-nowrap` 추가로 해결.
- 포트폴리오 "오늘 변동" 카드의 "AI 리포트 연동" 텍스트가 두 줄로 밀리던 문제(처음 보고된 건
  사실 이거였음 — 위 사이드바 건과는 다른 요소) — 숫자용 큰 글씨 크기(`text-3xl`)를 그대로
  텍스트 라벨에 쓰고 있던 게 원인. `text-xl`로 줄이고 `whitespace-nowrap` 추가.
- 포트폴리오 화면 종목명/시세 버그 — 별도로 이미 고치고 보고함 (`fix(portfolio): ...` 커밋).
- AI 예측 상세 페이지(10번)와 종목 상세 페이지(06번)가 종목명을 못 띄우던 버그 — 포트폴리오에서
  쓴 이름 해석 함수(`resolveStockName`)를 공유로 빼서 두 페이지 모두에 적용.
- AI 예측 상세 페이지의 "추론 결과 분석 리포트"가 항상 빈 문구로 뜨던 문제 — **원인은 백엔드
  버그가 아니라 UX였다.** `GET /ai/predictions/{code}`는 5분 주기 push 결과(리포트 없음)를
  캐시로 먼저 보여주고, 실제 Gemini 분석 리포트는 "새로고침" 버튼이 트리거하는 ONCE 요청에서만
  생성된다. 백엔드에 직접 ONCE 요청을 넣어 `/ai/callback` 콜백까지 끝까지 확인했고, Gemini가
  실제로 상세 리포트(요약/피처분석/시간가중치/시장환경/투자유의 5개 섹션)를 정상 생성하는 것도
  확인했다. 다만 기존 안내 문구("백엔드 응답에 상세 분석 리포트가 포함되지 않았습니다")가 마치
  오류처럼 읽혀서, "아직 요청 안 함 + 새로고침 눌러보라"는 문구로 바꿨다.

- AI 예측 상세 페이지의 리포트 카드 안에 마크다운 표 문법(`| 구분 | 확률 | 해석 |` 같은 줄)이
  그대로 텍스트로 보이던 문제 — 구분행(`| :--- |`)은 버리고, 데이터행은 셀을 " · "로 이어붙인
  한 줄로 바꿔서 해결.

## 2026-10-28 갱신: "위장 기능"(동작하는 것처럼 보이지만 실제로 안 되는 기능) 정리

프론트/백엔드 전체를 훑어서 "하드코딩이거나 가짜로 동작하는 척하는" 기능을 찾아 전부 실제
기능으로 교체했다. Google 로그인(OAuth 키 미발급)만 빼고 전부 처리:

- **관심 종목(즐겨찾기) 영속성** — 로컬 상태만 바뀌고 저장이 안 됐음. 백엔드에 `Favorite`
  테이블/`/favorites` CRUD 라우트를 새로 만들고 프론트를 연결. 실제로 추가 → 새로고침해도
  유지되는 것 확인.
- **오늘의 뉴스 / 오늘의 공시** — 완전 목업 배열이었음. 이미 레포에 있던 Naver 뉴스 검색 API +
  DART 공시 API 연동 코드(AI 리포트용으로 만들어져 있던 것)를 가볍게 재사용해서 실제 데이터로
  교체. DART는 "현대차" 같은 약칭이 공식 등록명과 안 맞는 버그가 있어 종목코드로 조회하도록
  고침.
- **최근에 본 종목** — 고정 3종목 목업이었음. 종목 상세 페이지 방문 기록을 로컬에 남겨서
  대시보드가 실제 조회 이력 + 실시간 시세로 보여주도록 교체.
- **수익분석 / 자산 탭** — 월별 수익 그래프가 전부 하드코딩 숫자였음. 이미 실제 KIS 모의계좌
  데이터를 쓰고 있던 자산 탭과 동일한 소스(`/account/assets`)로 교체해서 실제 평가손익/종목별
  손익을 보여주도록 함. "채우기/보내기" 버튼(onClick 없음)과 판매수익/배당금/이자(항상 0으로
  하드코딩)는 모의투자 계좌가 실제로 지원하지 않는 기능이라 제거하거나 "미지원"으로 정직하게
  표시.
- **주문내역 탭** — 완전 하드코딩 4행이었음. 알고 보니 수동 주문 자체가 `TradeLog`에 전혀
  기록되지 않고 있어서(백엔드 갭), 주문 시도마다 성공/실패 관계없이 기록하도록 고친 뒤 프론트를
  연결.
- **알림 페이지 + 사이드바 뱃지** — 조작된 가짜 알림 3개 + 뱃지 숫자 "3" 고정이었음. 알림 전용
  백엔드는 없어서(범위 밖), 실제 체결 내역(`/trade/history`)을 알림으로 재구성. 뱃지는 최근
  24시간 체결 건수(0이면 숨김)로 교체.
- **설정 페이지** — "알림 설정"/"보안 설정" 카드가 클릭해도 아무 일도 안 했는데 hover 효과만
  있었음. 실제 백엔드가 없는 기능이라 "준비 중" 뱃지로 명시.
- **대형주/소형주 배분 로직** — `cap_type` 분류가 TODO로 남아 항상 기본값만 쓰던 죽은 코드였음.
  `ticker_universe.rank` 기준으로 실제 분류하도록 구현.
- **닉네임 변경** — "변경사항 저장" 버튼이 아무 동작도 안 했었음. 실제 `PATCH /users/me`로
  저장되도록 연결(중복 닉네임은 409로 처리).

### 기능 테스트 결과 (Playwright로 실제 클릭/제출까지 재현)

- 관심종목 추가 → 새로고침 → 유지됨: **확인**.
- 닉네임 저장 → 새로고침 → 유지됨: **확인** (처음 테스트 때 입력 필드를 잘못 짚어서 실패로
  보였는데, 올바른 필드로 재확인하니 정상 동작).
- 수동 매수 주문 제출 → 실제 KIS 모의투자 서버가 "모의투자 장종료입니다"로 응답(테스트 시각이
  장 마감 이후라서 정상적인 거부) → 그 실패 기록이 주문내역 탭에 실제로 뜨는 것까지 확인(이름
  해석, 상태 배지 포함). AI자동거래내역 탭에는 안 섞이는 것도 확인.
- 알림 피드는 FAILED 상태 거래를 올바르게 제외하는 것 확인(현재 체결된 거래가 없어 빈 상태로
  뜨는 게 정상).
- **장중에만 테스트 가능한 부분**(실제 체결 → 보유 종목 평가손익 → 체결 알림까지 이어지는
  전체 흐름)은 KIS 모의투자 거래시간(평일 09:00~15:30 KST) 제한 때문에 이번엔 끝까지 확인하지
  못했다. 코드 경로(주문 로그 기록, 자산/수익분석 데이터 소스, 알림 필터)는 전부 확인됐고,
  남은 건 실제 체결 데이터가 들어오는 것만 보면 되는 상태.
