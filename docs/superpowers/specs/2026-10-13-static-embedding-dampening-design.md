# 설계: 정적 임베딩 과의존 억제 재학습 (2026-10-13)

## 배경 / 문제

라이브 운영 중(2026-10-06~) 5종목 중 2종목(삼성바이오로직스 207940, 셀트리온 068270)의 예측 확률이
입력 피처가 실제로 크게 움직여도 거의 고정돼 있다(207940 매수확률 표준편차 0.0055, 범위 0.027).

원인 조사 결과:
- **라벨 문제 아님**: 2026-10-07~10-12 급락 구간에서 207940의 실제 다음날 수익률 교차단면 순위는
  10.5%(명백한 매도) → 85.5%(명백한 매수)로 크게 요동쳤다. 그날그날 분산도 2.3~3.6%p로 충분히 컸다.
  즉 배울 수 있는 진짜 신호가 있었다.
- **모델이 그 신호를 종목별로 못 쓰고 있음**: 같은 기간 모델 출력은 이 종목들에서 거의 안 움직였다.
- 기존 진단(`docs/signal_diagnosis.md`)과 일치: raw IC는 대부분 종목 고정효과이고 타이밍 성분은 약함.
- 이미 시도했던 `static_const=True`(정적변수를 상수로 — 사실상 제거)는 OOT가 val을 못 따라가며
  과적합됐다(기록: `project_ai_gentle_viking_re_redesign.md` 2026-09-28/10-01 섹션). "완전 제거"는 실패.

- 채택 기준(둘 다 충족해야 교체):

  2. 아래 "종목별 반응성" 지표가 현재 서빙 중인 5종목(특히 207940, 068270) 전부에서 뚜렷이 개선될 것 —
     다른 종목에서 새로 반응성이 죽는 종목이 생기지 않을 것.

## 접근 1(주): 정적 임베딩 전용 드롭아웃 + weight decay

- `tft-torch` 포크에서 정적 컨텍스트 벡터(static embedding)가 GRN/변수선택 경로로 들어가기 직전에
  별도 드롭아웃을 추가한다(기존 전역 dropout과 별개의 하이퍼파라미터).
- 정적 임베딩 레이어 파라미터에만 적용되는 weight decay를 추가한다(현재 전역 weight_decay=0,
  동적 경로는 그대로 0 유지 — 정적 경로만 규제).
- 새 레시피를 `training/run_e4_experiments.py`의 `RECIPES`에 추가하고, 두 하이퍼파라미터(정적
  드롭아웃 비율, 정적 weight decay)는 2~3개 값만 좁게 스윕한다(전체 Optuna 재탐색 아님 — 시간 제약).
- **새 평가지표 "종목별 반응성"**: OOT 구간에서 종목별로 예측 확률(또는 score)의 **일별 표준편차**와,
  **예측 score와 실제 다음날 교차단면 순위(percentile)의 종목별 상관계수**를 계산한다. 지금 챔피언에서
  207940/068270이 이 두 값 모두 바닥(거의 0)인 것을 기준선으로 삼아, 후보가 이걸 끌어올리는지 본다.
  순수 함수로 구현하고 합성 데이터로 테스트한다(TDD).
